🎓 College Placement Information System

A lightweight PHP-based web application designed to help B.Tech CSE students browse placement opportunities and submit job applications.

✨ Features

👨‍🎓 Student registration

🔐 Password hashing

💼 Job listings

📄 Job applications

📁 Lightweight .txt file storage

⚡ Simple and easy deployment

🛠️ Technologies

HTML5

CSS3

JavaScript

PHP

XAMPP

Git & GitHub

📂 Project Structure

college-placement-system/
├── index.html
├── register.php
├── jobs.php
├── apply.php
├── students.txt
├── applications.txt
└── README.md

🚀 Run Locally

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/college-placement-system.git
cd college-placement-system

2. Using XAMPP

Place the project inside:

C:\xampp\htdocs\

Start Apache from XAMPP.

3. Open in Browser

http://localhost/college-placement-system/

🔐 Note

This project uses flat-file storage and is intended mainly for educational purposes. For production use, MySQL, stronger authentication, CSRF protection, access control, and secure data storage are recommended.
